# Poster MVP Demo

Автономный прототип подстановки афиши в видео: результат и переключатель трёх постеров.

Демо: https://tmko16.github.io/poster-mvp-demo/

## Файлы

- `index.html` — вся страница: HTML, CSS, JavaScript, WebGL-шейдеры, трекинг и встроенные медиа.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Просмотр и обновление

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.
Для публикации обновите `index.html` в ветке `main`: GitHub Pages публикует корень этой ветки.
